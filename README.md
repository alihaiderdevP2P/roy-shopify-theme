# ROY – Shopify Theme
Streetwear theme: home, collection, product, cart, buy-more-save-more messaging.

Install: Shopify Admin > Online Store > Themes > Add theme > Connect from GitHub (or upload zip).

Admin setup:
- Settings > Payments > Manual payment method > Cash on Delivery (COD)
- Settings > Shipping: Rs 200 flat, free over Rs 2500
- Discounts > Automatic: 5% off 3+ items, 10% off 4+ items
- Navigation > main-menu: Home, Men, Women, Anime Mood, Over Sized Jerseys
